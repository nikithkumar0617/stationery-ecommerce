# Stationery E-Commerce Website

## Project Overview

Develop a stationery e-commerce website inspired by Amazon and Flipkart for a stationery store.

Technology Stack:

* Frontend: HTML, CSS, JavaScript, Bootstrap
* Backend: Python Flask
* Database: MySQL
* Version Control: GitHub
* Hosting: GoDaddy

---

## User Roles

### Customer

* Register
* Login
* Browse Products
* Search Products
* Add to Cart
* Checkout
* Place Orders
* View Order History
* Apply Coupons
* Online Payment
* Cash on Delivery

### Admin

* Login
* Add Products
* Edit Products
* Delete Products
* Manage Categories
* Manage Coupons
* Manage Inventory
* View Orders
* Update Order Status
